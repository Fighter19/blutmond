Blutmond

An engine for Metroidvania-style GBA games, running in the browser.

EditorRooms, sprites, scripts and songs of the test project. Export (Ctrl+E) downloads the game as a .gba file for any emulator. GameThe test level, played with the keyboard or a gamepad. game.gbaThe test level as a ROM, built by CI, for mGBA or another emulator.
  • Game keys: arrows to move, X or Space to jump, Z is B, A and S are L and R, Return is Start.
  • In the browser, edits last as long as the page. Run, Sync and the Xboo cable need the desktop editor.
  • Source and documentation: github.com/Fighter19/blutmond.
